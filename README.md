
# 🌱 AgroSmart AI – Crop Recommendation System

## 📌 Project Overview

AgroSmart AI is a Machine Learning-based Crop Recommendation System developed using Python and Streamlit. It recommends suitable crops based on soil nutrients and weather conditions. The system uses Decision Tree and Random Forest algorithms to predict suitable crops and help users make informed farming decisions.

## 🎯 Objectives

* Recommend suitable crops based on soil conditions.
* Analyze soil nutrients and weather parameters.
* Apply Machine Learning algorithms for crop prediction.
* Provide an easy-to-use web application for crop recommendations.
* Support smarter agricultural decision-making.

* Decision Tree Classifier

## 📊 Dataset Information

The dataset contains 10,000 records with the following features:

* Nitrogen (N)
* Phosphorus (P)
* Potassium (K)
* Temperature
* Humidity
* Soil pH
* Rainfall
* Crop Label

Data preprocessing includes handling missing values, checking duplicates, and treating outliers.

## 📈 Model Performance

* Decision Tree Accuracy: Approximately 63%
* Random Forest Accuracy: Approximately 76%

Random Forest performed better than Decision Tree and was selected for crop prediction.

## 🌿 How It Works

1. User logs into the AgroSmart AI application.
2. Enters soil nutrient values (N, P, K).
3. Enters weather conditions (Temperature, Humidity, Rainfall).
4. Provides soil pH value.
5. Clicks on Recommend a Crop.
6. The trained Machine Learning model predicts a suitable crop.
